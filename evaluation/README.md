# Evaluation materials

The evaluation adapts Liang and Lu’s (2026) contribution-removal criterion into a sequential outcome-survival test. It asks whether each step’s outcome can be derived without the specified AI contribution, then traces the consequences through reconstruction.

A retrospective evaluator may know the target outcome. A new argument from retained evidence and sources can establish survival even without the original process history. What the researcher would actually have discovered remains a separate question.

`backtest_protocol.md` defines retained inputs, individual and joint removals, replacement derivations, and evidentiary limits. `audit_instructions.md` explains the sequential assessment form. `analysis_plan.md` defines descriptive summaries. `rating_rubric.json` separates substantive quality from dependence.

The Niu Lai example contains an authored five-step survival review under a declared corpus. It is inspectable reasoning for method illustration, not an observed unaided research process or independent expert validation. Empty assessment forms remain unestimated.
